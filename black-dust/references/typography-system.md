# 文字与拼图系统

## 连续底图先于切割

中文、英文、Logo 和品牌字必须先在无拼缝连续底图上完成。优先使用确定性排版或用户已确认的字稿；逐字、逐词核对后冻结该底图，再建立拼图刀模。不得让生成模型在已经切割的拼图上重写文字，也不得用旧拼缝参考作为新底图再次叠缝。

## 中文保护

- 锁定文字内容、字形骨架、重心、笔画粗细、字腔、标点和行间关系。
- 拼缝可以穿过字面，保护区只降低窄缝物理层的强度，不能把文字浮在未切纸面上。
- 缺口默认避开横竖撇捺的连接点、封闭字腔、易混淆部件和小字号文字；不得因缺块使字被读成另一个字。
- 墨尘式字面可以保留真实炭棒擦痕、纸齿和局部消散，但喷点不能取代笔画边缘，也不能把每个字都做成同方向的颗粒尾巴。

## 英文保护

- 锁定大小写、拼写、撇号/连字符等标点、字腔、基线、字距和行距；`I’M BLACK DUST` 的撇号与 `B/A/D` 等识别结构必须单独检查。
- 缺口避开形成字母身份的主干、交叉点和封闭字腔；拼缝仍可低调穿过文字，使字与留白属于同一拼板。
- 不以生成模型偶然正确的一张证明稳定排字。批量任务须对每张实际输出重新 OCR/人工校对。

## 中英组合与层级

先确定主标题、英文识别词、副标题和 Signal Orange 锚点的层级，再把整套排版冻结为连续底图。中文与英文不能竞争同一视觉层级；橙色只作小面积锚点，不用于给所有散件描边。留白、文字、炭棒和粉尘都是同一张先印刷后压切的拼面。

## 字体骨架与木炭书写

确定性排版的目标是文字正确，不等于使用无纹理的印刷字。社媒与文章封面默认采用“可校对骨架 + 木炭落笔表面”：

- 中文文章标题优先选择具有手写起收笔、重心变化和撇捺节奏的字形骨架；品牌主字可更稳定，但仍要有笔压厚薄、纸齿透出和轻微边缘脱落。
- 英文可保留 condensed grotesk 的编辑骨架，但字面必须经过方向性炭擦、局部叠压与纸齿透出；不能是纯色矢量贴纸。手写英文适合人物随笔、旅行与情绪主题，机械/产品主题可更理性。
- 纹理必须服从笔画：沿笔势的短擦痕、低频浓淡和极轻软晕可以存在；均匀盐胡椒点、整圈破边、统一喷溅尾巴和发光描边禁止。
- 主题决定字的节奏：人物/情绪更松、更有呼吸；产品/机械更紧、更克制；建筑/风景强调横向留白与结构；品牌介绍保持可复用识别。
- 小字号副标题优先可读性，只做低强度炭质化；不要把所有层级都做成同等粗糙。

项目脚本 `cover_compositor.py` 使用可核对的字体骨架，并从当前底图采样真实纸面高频纹理，再叠加确定性低频炭压和少量顺笔势短擦来合成字面。炭量按角色分配：主标题必须形成紧实炭黑主体并保留细微纸齿，英文标识略轻，副标题再轻一档；不得把所有字统一做成发灰、半透明的旧印刷。它不随机撒点、不画贯穿整字的机械划痕；相同输入与参数可重复生成。

文章标题允许使用 `--title-accent` 对一个语义重点做 Signal Orange 锚定，并用 `--title-underline` 为一个短语加入木炭重点划线。划线必须跟随对应行的真实字宽与基线，采用中段重、两端收力、轻微弧度和少量顺笔势露纸；不使用规则矢量直线、荧光笔色块或贯穿整行的装饰横杆。划线并入标题保护框，切图后不得被洞口或散件遮挡。

中文标题、中文副标题与英文标识必须进入同一**材料系统**，但不强制使用同一种手写骨架。品牌/材料型封面使用高重量、稳定的中文骨架与 condensed/narrow 的 `SKILL`，副标题采用清楚的中文骨架；三者共享纸齿、低频笔压、短擦和轻微炭晕。文章主题型才优先使用更松的中文手写骨架与带基线起伏的英文手写骨架。禁止为了“手绘感”把品牌识别做散、把英文挤入大字，或让所有层级同样粗糙。

品牌锁定字组有两个允许布局：竖向社媒采用“墨尘 → SKILL → 副标题”三层分离；横版品牌/文章首图采用“墨尘 + SKILL”同行或错位成组，副标题独立在下。任何布局中，实际字面不得重叠；只允许文字保护框因安全余量轻微相交。

## 品牌字组最终标准

品牌/Skill 封面使用以下准确字稿，不得同义改写、漏字或把探索稿混入：

- 主字：`墨尘`
- 英文识别：`SKILL`
- 副标题：`把灵感，拼成画面`

最终视觉按以下规则收口：

1. “墨尘”是第一识别层，字面厚实但不是实心矢量块；保留可见纸齿、局部笔压差和少量顺笔势短擦，轮廓不得被均匀毛边、盐胡椒点或伪旧裂纹破坏。
2. `SKILL` 使用窄体、宽字距的编辑骨架，表面与中文字共享纸齿和炭压。品牌版允许它使用 Signal Orange；不得挤进“墨尘”内部或缩成难读的小署名。
3. 副标题完整独立成行，只将第一个“拼”设为 `#FF5A1F`，其余字保持 charcoal black / graphite gray；不得再给第二个字或整段上色。
4. 只在“拼成画面”下使用一条自然木炭重点划线。划线从短语实际字宽生成，中段压力最重、两端收力并有轻微弧度和顺笔势露纸；禁用上下两条装饰短横、规则直线、荧光笔色块或跨越整行的横杆。
5. 字、标点、强调色与划线必须在拼图切割前写入同一连续底图；全部并入一个文字保护集合。洞口、散件、主体、炭棒断口和高密粉尘不得遮挡它们，拼缝仅按保护区规则减弱而不能消失。
6. 竖版与横版可以重排，但不重新设计层级：3:4 采用三层分离；5:2 采用左上“墨尘 + SKILL”锁定字组和下方副标题。主字与副标题在目标比例适屏及约 320px 宽缩略图中都必须可读，不以放大查看代替验收。

文章主题封面遵循同一材料逻辑，但不强制使用品牌副标题。标题可选择至多一个语义重点着橙、至多一条与该重点相关的短语划线；没有清楚重点时宁可全部炭黑且不划线，不能把品牌模板机械套到每篇文章。

## 缺口与散件

- 先为全部关键文字建立保护框，再从外围炭痕、粉尘明暗过渡或次要图案中选择 `recognizable` 裁片。
- 洞口与散件必须共用同一 mask、同一原位置顶面和同一光向；旋转可以改变展示角度，不能镜像、改色、重绘或重新生成块面文字。
- 若用户明确要求从文字中取块，只能在 exact composite 中执行，并同时交付 `assembled_output`；拼回后字形、标点、字距和笔触必须连续。

## 验收

1. 连续底图：文字内容、字形、标点、字腔、字距和层级正确。
2. 整板：忽略缺口与散件时，文字区和留白区都能在适屏视图读出同一套标准拼缝。
3. 缺块：默认不破坏关键笔画；每块仍含可辨认的原始炭粉或明暗图案。
4. 拼回：`assembled_output` 恢复完整文字与原图案，mask/content/assembled hash 全部通过。
5. 状态：结构审计只能标为 `structural_pass`；文字审美和品牌准确性须由实际视觉检查确认，用户未确认前不得标为 `user_approved`。
