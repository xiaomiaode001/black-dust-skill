# 输出测试与审美验收

## 先说明覆盖范围

每次在最终 manifest 或审计记录中保留：生成工具/模型（未知不猜）、Prompt、参考角色、修订原因、合成参数、最终输出、未旋转块与 manifest。普通候选与失败过程稿使用临时目录，最终选择完成后无需长期保存或对用户呈现；只有用户要求 A/B、过程复盘或保留历史时才保存对应版本。源图仅能解码显示不等于通过文件校验；遇到损坏 PNG，使用可读取的同组参考或请求重新导出，不静默改写原图。

把四个状态分开：

- `generated`：真实生成并保存；
- `structural_pass`：文件与配对校验通过；
- `visual_candidate`：代理视觉审查后可供用户选择，允许明确列出不足；
- `user_approved`：用户实际确认。不能由代理自行升级。

一个工具各一张的样本只验证该批输出。多模型兼容、输入身份保真、批量稳定性、不同平台尺寸，需要各自的样本，不能外推。

## 八类主体与两类文字最小测试矩阵

| 类别 | `standard-v5 knob_ratio` | 必看细节 | 常见失败 | 修订优先级 |
|---|---:|---|---|---|
| 人物 | 0.18 | 两眼、鼻口、侧锋灰面、顺形短线 | 脸被切格；皮肤像裂陶/浮雕 | 重建灰面与提亮，保护头部；拼缝按 75–90% 合成强度保留 |
| 动物 | 0.18 | 眼鼻、耳形、成束毛流、物种特征 | 粉尘围脖；统一锐化毛发 | 连续长短毛笔触、暗部归组 |
| 静物/产品 | 0.19 | 玻璃反光、金属灰带、布褶排线；部件 | 只像照片加纹理；缺口排队 | 类别画法差异与完整轮廓保护 |
| 建筑 | 0.17 | 垂直线、侧锋墙面、雾层轻擦 | 没有绘制痕迹；强行补炭渣 | 检查结构笔线和软硬边，保留雾景 |
| 风景 | 0.17 | 远中近层次、连续引导线 | 亮天空上的块抢焦点；满图同细节 | 中等对比摆位，降低远景频率 |
| 机械 | 0.19 | 面板、关节、硬表面层次 | 石板化、死黑散落块、遮肩甲 | 完整金属平面、暗灰负空间、扩保护框 |
| 抽象 | 0.18 | 笔势/擦除负形；实物分支才验断面 | 任意烟团；均匀喷溅 | 明确绘画或实物分支，不默认碎裂 |
| 社媒封面 | 0.20 | 主标题、中文、目标比例、缩略图、单一橙色重点、单条木炭划线 | 强缝切字、错字、多处橙色、双横线、平面印刷字、假称生成图精确橙 | 先排版后切割、逐字校对、强调/划线计数、裁切复核 |
| 中文文字 | 0.18 | 字形、关键笔画、字腔、标点、留白层级 | 缺口改字；墨点吞掉笔画；文字浮在未切底纸 | 冻结连续字稿，保护识别核心，拼缝保留 |
| 英文文字 | 0.18 | 拼写、大小写、撇号、字腔、字距 | 漏字/错字；撇号消失；字距被缺口破坏 | 逐词校对，保护标点和字母结构，拼回复核 |

八类主体拼图回归必须逐类记录 `material_preset`、网格、保护区、缺块/散件数、manifest、结构审计和视觉结论。涉及文字时再分别增加中文、英文样本与逐字/逐词结论。类别基线为：人物/动物/机械及暗调静物用 `deep-charcoal`，建筑/风景及中灰物体用 `graphite-matte`，抽象/社媒/文字及浅调产品用 `ivory-board`。某类通过不能替代另一类；本轮只有十个样本分别通过，才可描述为“八类主体与两类文字结构回归通过”。

## 四种观察尺度

1. 全图适配屏幕：先做整板盲检——暂时忽略或遮住洞口与散件，整幅仍须由 edge-to-edge 的成熟标准拼块组成，主体区、负空间和画布边缘的共享边都可追踪；若第一眼是平面画、随后才靠洞/散件识别拼图，直接失败。随后再看视觉重心，洞/块是否抢过主体，分布是否僵硬。
2. 100% 局部：检查 `standard-v5` 的清楚圆旋钮、宽颈、无细小收口的连续切线、圆滑凹槽和相邻共享边；颈部半宽应保持圆头半径约 50–58%，不得出现内卷尖钩或突然折向。拼缝只能在窄带内出现约 2px 单侧暗槽、左上光源下的方向性双肩和近中远三段低强度衰减，亮暗值相对局部原画计算，保护区保留同一预设约 75–90% 强度。深木炭笔触须连续保留。再检查洞口是否为上/左接触暗部、下/右内壁反光的凹陷极性，纸板是否为连续粗细双尺度纤维；`ivory-board` 在 1980×792 应为约 4px 暖色薄切壁且无固定暗圈，其他预设通常为 5–6px。散件中央顶面仍是缺口原位置内容，仅极窄面缘有源明度相对斜面，并有近远两级接触影。不得用平灰洞底、固定灰白线、暗色光晕、盐胡椒噪点、强描边或全图浮雕掩饰物理感不足。
3. 缩略图：横图约 320px 宽，3:4 封面约 270×360；应先认出主体/标题，再看见拼图。机械深色块可能在此丢失，不能仅以原尺寸可见就通过。
4. 配对与拼图构图：用户指定 3 组时必须得到 3 个洞口与 3 个同源散件；默认每个散件都应同时具有凸头与凹槽，形成可识别的标准圆头/宽颈结构。同时 `content_profile.recognizable_content` 为 true，裁片带有能凭肉眼回接的木炭纹理、明暗过渡或局部图案；若负空间只能提供浅纸纹，可明确使用 `any`，但不得从主体取块或擅自减数。散件应以薄纸板厚度、短近影和弱远影贴在拼面上，不能像厚塑料按钮或悬浮贴纸。不规则感来自三组洞与散落块的间距、角度和疏密，并与标题、主体和平台裁切形成负空间标点。逐对核对共用 mask、`mask_sha256`、未旋转顶面的 `content_sha256`、内容剖面、旋转记录与 `mirrored: false`，并查看 `assembled_output` 是否恢复完整连续图案。若圆弧带细小收口或尖钩、刀线像任意波浪、洞块平均排队、全部堆在一个象限、默认模式出现全凸/全凹散件、块形/内容与洞不对应，均不通过。

## 品牌封面文字收口检查

品牌模式只有同时满足以下项目，才可从 `structural_pass` 进入 `visual_candidate`：

1. 文案逐字等于“墨尘 / SKILL / 把灵感，拼成画面”，没有“黑尘”、错别字、变体标点或多余宣传语。
2. 副标题仅第一个“拼”为 `#FF5A1F`；正式确定性合成读取并记录品牌色，生成模型直接出字只能标为实验稿，不能声称精确色值。
3. 全画面只有一条重点划线，位于“拼成画面”下方；它呈自然炭笔压力与收笔，不是两条短横、平直矢量线或印刷装饰。
4. “墨尘”、`SKILL`、副标题、标点和划线全部包含在连续底图与拼图保护框中；洞口、散件、主体和粉尘路径均不遮挡。
5. 3:4 以实际 3:4 尺寸验收；5:2 必须输出精确 5:2 像素（例如 1500×600 或 1980×792），不得以近似 16:9 裁切冒充。
6. 目标比例适屏与约 320px 宽缩略图中，先读到品牌与副标题，再识别材料主体和整板拼图；若只能放大才看清字或拼缝，不通过。

## 硬门槛与审美反馈

任何一一配对失败、mask/content/assembled 哈希不一致、镜像、错误文字、非目标比例，都不能判定成品通过。完整语义主体禁区为硬失败条件：洞口源格或散件的旋转角点、侧壁、近影、远影只要与主体外轮廓、断口、粉尘/碎屑路径、关键投影、引导线或文字相交，就必须重排；“没挡住中心”不构成放行。洞口与散块必须在形状、方向和原图顶面内容上严格一一对应；建筑、产品等结构图案还必须在 assembled proof 中连续。若整板盲检失败，即使洞块配对全部正确也不能通过视觉验收。`structural_pass` 只证明结构审计通过，不等于 `visual_candidate`，更不等于 `user_approved`；修订后必须重新跑校验并重新看图。

以下全局伪材质均直接返工：全图 emboss/normal-map、逐块棋盘亮度、固定灰白拼缝、整圈白描边、统一龟裂贴图、盐胡椒纸纹、随机墨点或喷溅。允许的物理变化只位于拼缝窄带、洞口和散件占用范围；散件顶面必须保持源裁片不变。

审美按「可保留 / 需微调 / 需重做」记录理由，不伪造精确分数或胜率。先检视绘画的形体、灰阶、笔触、提亮与细纸齿，再检查主体层级、纸板和文字。只有实物崩解分支才验颗粒尺度过渡，不把“没有撒粉”当失败。

底图专项：原图与输出的同类局部并看；指出笔触如何塑造形体。照片式微细节加噪点、全图卷曲浮雕纹、皮肤和背景同一花纹、每类都有散点尾巴，均须返工。默认底图不达标时暂不合成拼图；用户明确要求提前试作时记录 `stage: puzzle_study` 与未获批的 `base_status`，配对通过不能抵消底图问题。

原画精修增加四项观察：人物同时看灰面与外围毛边，不能以减少皮肤刻纹交换更机械的边框；静物同时看布褶体积、玻璃完整反光和局部笔压，不能从刻线退成塑料般光滑；风景同时检查远景频率与原有云势/大明暗，不能将减纹理误做全局柔焦或改天气；实物炭棒同时检查低矮长方压制形、顺长轴片层/纤维纹、吸光主体与克制棱边光、单端斜向纤维断口，以及贴地碎片—粗粒—细粉的连续尺度递减。任一结果若读成圆柱铅笔、树枝、规则砖块、蜂窝焦炭、熔岩皮、黑烟或均匀喷点尾迹，均不通过；不用“裂纹更多”或“颗粒更少”作为单向加分项。

局部改善仍可与整体未达标并存。记录具体保留项和退步项，不能把“有进步”升级为定稿。用户要求整体原画对齐后再拼图时，即使某一类已成为候选，也不自动进入该类的拼图构图；只有用户明确的新阶段要求才切换。

首次失败后只改一个主要变量再比较。参数探索可以改变拼块数和网格，但须明确这不是严格单变量 A/B。不喜欢某一类别时优先修类别分支，不把全局模板改成该类专用。

## 模型适配

共用材质/保护/配对规则，区分三种执行能力：支持参考图的生成、支持保真编辑的生成、只支持文本的生成。厂商参数只有确认版本后才写入适配文件；不能把自然语言写了 16:9 当作已经获得目标像素。严格配对仍走确定性后处理。

扩展发布前，每类至少增加不同明暗/构图输入与多个种子，在最终测试记录中汇总各模型的失败类型、修订次数和最终人工选择，不默认保留或展示失败图片。社媒另测 3:4、项目自定 5:2、微信公众号横/方图；只测 3:4 不代表全部通过。
