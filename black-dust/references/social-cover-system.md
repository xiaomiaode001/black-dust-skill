# 社媒封面与 Typography

## 已批准的品牌封面基准

以 `../assets/skill-cover.png`（3:4）和 `../assets/social-cover-5x2.png`（5:2）作为品牌/Skill 主题封面的审美基准。其中 5:2 资产是 2026-09-14 用户明确批准的 v10 定稿标准，状态为 `user_approved`；后续不得用实验稿替换。它们是 `style_reference + typography_reference + puzzle_reference`，用于约束质感和构图，不作为可直接取块的连续底图，也不替代确定性配对审计。

- 暖灰象牙纸板贯穿全画面，细纸纤维与浅压切拼缝同时可见；拼图首先是一整张真实压切纸板，不能是平面黑线网格。
- 实物炭棒采用 [visual-system.md](visual-system.md) 的“实体炭棒定稿形态”：低矮修长的长方压制炭条、顺长度的片层/纤维纹、克制棱边石墨光、单端斜向纤维断口，以及近端碎片—中段粗粒—远端细粉的贴地尺度递减；粉尘必须有明确物理源头。
- 品牌字组固定为“墨尘 / SKILL / 把灵感，拼成画面”。中文字面、英文和副标题共享纸齿、炭压与短擦，不使用纯色印刷贴字。
- 副标题仅允许一个橙色重点：默认突出“拼”；其余文字保持炭黑。只使用一条位于“拼成画面”下方的自然木炭划线，要求干笔起势、压力变化和收笔渐细；禁止恢复上下两条装饰短横或平直矢量横杆。
- 5:2 品牌横版使用左上品牌字组、下半部横向炭棒主轴和向右展开的粉尘路径。3 组洞口与散件分布在文字、炭棒、断口及粉尘路径之外的负空间，保持非对称疏密；每组仍须由确定性工具实现同一 mask、同源像素和拼回证明。
- 5:2 定稿的浅色拼图材料使用 `ivory-board`：1980×792 时切壁视觉厚度约 4px，凹底从暖灰粉纸板 `#D0BCAE` 起步，上/左是纸芯遮蔽，下/右为窄而克制的反光唇。散件顶面逐像素继承原格内容，只允许极窄、随源明度变化的边缘斜面；禁止平灰洞底、固定黑白整圈、暗色光晕、厚塑料边或悬浮贴纸影。

这两张基准只锁定**设计语法**，不要求逐像素复制其偶然瑕疵。后续 5:2 与 3:4 品牌封面必须保留字组、单一副标题橙色重点、单条木炭划线、下方材料主轴和三组负空间配对；允许随平台安全区调整相对位置与字号。若基准图中的散件内容不能证明与洞口同源，以确定性切块结果为准，不能为“长得像参考”牺牲真实配对。

## 三阶段流程

1. **底图阶段**：按内容选炭笔绘画或实体炭棒，预留负空间；实体炭棒应保留原参考的棒身、断面、碎屑与细粉构成的整体意境，不默认减尘。禁止预生成拼缝、洞和块；默认不要求模型生成最终中文。用户指定先验原画时，在其确认前停留于本阶段。
2. **排版阶段**：用确定性文字工具加入标题、英文、标点与强调色，再检查缩略图和平台裁切。连续画面的最终文字在切割前完成。
3. **拼图阶段**：从完成排版的画面统一制缝、挖洞、取块。文字区域降低拼缝强度，禁挖关键字；不得在切割后重新排版导致块面与源图不符。

社媒封面默认使用 `speed_profile: rapid`：新主题最多一次底图生成，排版与拼图走本地确定性阶段；严格命中已批准底图时使用 `instant`。洞口物理层在每个 mask 的局部外接框内计算，避免为三处稀疏缺口重复处理整张 5:2 画布，但不得省略首次 exact-pair、assembled proof 和视觉 QA。

若无法使用确定性排版工具，交付无字底图、精确版式说明和文字内容，不要把模型生成的错误中文当成最终成品。

项目内置确定性排版入口：

```powershell
python scripts/cover_compositor.py clean-base.png typeset-base.png `
  --manifest typeset-base.cover.json --preset brand-wide --mode brand
```

文章主题首图使用 `--preset wechat-lead --mode article --layout theme-title --title "文章主题"`。当文章主题就是品牌、材料或 Skill 介绍时，使用 `--layout brand-lockup --subtitle "把灵感，拼成画面"`，按横版品牌参考形成“墨尘 + SKILL / 副标题”的稳定字组。脚本只生成无拼缝的排字连续底图，并在 manifest 中记录逐字校对内容、文字框、平台安全区和 `puzzle_protected_boxes_normalized`。之后必须从这个输出重新切拼图；旧缺块不能移植到新标题。

文字必须占用负空间并处于场景之上。标题框既是缺口保护区，也是散件禁入区；当局部背景与字色对比不足时，只允许使用羽化的“擦淡炭层”安静背景，不允许增加可见矩形底牌。适屏缩略图中的标题仍须可读，主体轮廓、关键产品结构和文字框不得互相遮挡。

用户明确要求先看拼图设计时，可在固定无字底图上做 `puzzle_study`；这是拼面样张，不是完整社媒封面定稿。后续加入标题、强调色或改变比例，必须从更新后的连续底图重新切块，不能沿用旧块内容。

## 实物炭棒：保留材料意境

- 先读原参考的棒身轮廓与角度、顺长轴压实片层、自然浅裂、纤维状脆断面，以及掠光下的接触阴影。默认保持低矮长方炭条的清楚长轴和连续坚实体量；不要把所有细节替换成等距裂纹或统一多孔表皮，也不要改成圆柱铅笔、树枝、蜂窝焦炭或粗短煤块。
- 粉尘是构图的一部分时，保留其延伸方向、覆盖范围与疏密层次：断面附近相连的碎片，逐渐松开的粗粒，落入纸齿的细粉；其间有不等大小的露纸空隙。大面积铺陈可以成立，不以颗粒越少、越干净判定越高级。
- 区分“真实炭粉的丰富”与“附加墨点”：前者有源头、尺度梯度、重量、纸面接触与低矮阴影；后者是无来源的均匀圆点、悬浮烟团或装饰喷溅。绘画分支的禁撒点规则不能变成实物分支的强制减尘规则。
- 用户明确偏爱某张原作材料时，可直接以原图做去字、去拼图的底图编辑，尽量保护炭棒与碎屑区域。说明这是原图清理分支，不是假称独立生成的新构图，也不保证像素不变；逐一检查残留字痕、接缝、空洞形状和补绘区域。
- 纸纹、纸色和照明同样跟随原参考，不能为了“纸感”统一加厚纹理或变成黄色海绵表面。

输出测试可单独考察模型文字能力，但必须标注实验生成文字，逐字检查，不推翻默认确定性排版流程。生成图中的橙色不能宣称精确等于品牌十六进制色；正式品牌色在排版阶段指定并校验。

## 封面模式

### `brand`

用于 Skill 介绍、账号品牌页、作品集封面和固定栏目。主标题固定为“墨尘”，英文标记为 `SKILL`，副标题默认“把灵感，拼成画面”。竖版按三层分离，横版允许主字与 `SKILL` 形成同一横向锁定字组，但字面不得重叠；副标题始终独立成行。允许沿用实体炭棒作为下方材料主轴；不能每次重新发明品牌字样。

### `article`

用于一篇文章的主题图或封面配图。普通文章使用 `theme-title`：文章标题是第一识别层，`墨尘 / BLACK DUST` 降为 kicker 或署名，副标题可选。品牌介绍、材料说明或 Skill 主题文章使用 `brand-lockup`：按已确认横版参考保留“墨尘 + SKILL / 副标题”，不再另造中部标题。底图主体必须和文章主题建立内容关系，而不是无条件复制炭棒：技术、人物、产品、建筑、风景、抽象等主题先按对应主体分支完成连续原画，再进入同一排版—切割流程。

文章封面的优先级固定为：**主题可识别 → 木炭绘制真实 → 标题提炼 → 整板拼图质感 → 缺块配对**。实体炭棒只用于品牌材料、创作工具或“墨尘”本身作为主题的场景；其他文章使用与主题对应的人物、动物、产品、建筑、风景、机械或抽象原画，保留其随形排线、擦揉灰面、提亮与自然边缘。禁止用统一炭棒、粉尘或喷点模板覆盖所有文章类别。

文章标题规则：

- 先给出一句可在缩略图中读完的短标题；推荐 6–16 个汉字，过长时保留一个主句，其余移到副标题。
- 中文行间不做英文式超宽 tracking；断行按语义，不拆专名、数字单位或成对标点。
- 需要强化一个因果词或关键短语时，可保留一个橙色重点字，并在对应短语下使用一条克制的手绘木炭划线；不得同时给多行加下划线或把划线做成平滑矢量横杆。
- 标题、Logo、关键数字与标点全部进入缺口保护框；拼缝仍以约 75–90% 强度穿过，使字面属于整块拼板。
- 缺块从标题附近有可识别图案的次要区取样，不从大面积纯纸色、纯黑字面或橙色单色区取样。
- 文章主题发生变化时，重新生成/编辑连续底图、重新排字、重新切块与审计，不复用上一主题的散件。

## 构图骨架

- **横版品牌 / 文章**：文字簇与实体炭棒形成上下错位，粉尘承担向右延伸的阅读动势；3 组洞口与散件只能落在标题—主体之外的安静纸面或边缘负空间，禁止压在炭棒、断口、粉尘路径上。用“一处近距小簇＋一处远端反拍”组织六个视觉节点，不沿边平均排队。
- **3:4 社媒**：上部 35–42% 为标题区，中下部为单一主体和材料路径；使用 3 组缺块，可在右侧安静纸面形成两处错位回应，另一组在底部或对侧形成远端反拍。三组的洞与散件都不得抢文字、炭棒及粉尘路径，保留足够安静纸面。
- **2.35:1 文章首图**：不可替代标题、品牌和主体交点集中在居中方形安全区；左右只延伸气氛、粉尘或次要图案。使用 3 组缺块，以两侧负空间的疏密差和小角度变化避免短画幅被高反差散件切碎。完整横图和居中方裁切必须分别验收。
- **1:1 次条**：只留一个短标题、一个主体和 3 组克制配对，不压缩横版的全部信息。

洞口与散件是负空间标点，不是主体装饰。不规则感来自洞/块位置、距离、角度与密度的非对称组织：允许小簇，但必须有一处孤立回应或大片安静留白，不能全部堆在同一列、同一边距或同一象限。单个裁片仍使用标准圆头、宽而清楚的颈部与共享边，不能出现细小收口，也不能把刀模本身扭成随机云朵。

## 字体角色

### 墨尘

现代高重量中文黑体，轮廓清楚，允许轻度 charcoal texture / dry erosion / rough print，但不能侵蚀笔画骨架。

### SKILL

Uppercase condensed grotesk 或 narrow sans，wide tracking，建立理性编辑感。字面同样采样当前纸齿并带低频炭压，不能是平滑纯色矢量贴字。橙色模式使用 `#FF5A1F`。与“墨尘”同组时保留明确水平间隙；竖版位于主字下方时保留明确垂直间隙。

### 副标题

现代、干净、中等字重中文无衬线。“拼”可以使用 Signal Orange，其余保持 charcoal black / graphite gray。

品牌模式中“拼”为唯一的副标题橙色字，并在“拼成画面”下使用唯一一条木炭划线；这两项共同构成一个视觉锚点，不增加第二条线或第二组副标题色彩。文章模式按标题语义重新选择重点，不默认突出“拼”。

## 层级

默认顺序：

1. 主标题；
2. `SKILL`；
3. 副标题；
4. 主体；
5. Black Dust；
6. 缺失块。

主标题在缩略图中必须可识别。拼图线、缺口和尘化不能切断关键字；橙色只承担视觉锚点。

## 平台

实际尺寸读取 [platform-presets.yaml](platform-presets.yaml)。

- 小红书使用 3:4 竖版；标题区与主体在首屏形成清晰上下或对角关系。
- X / Twitter 按用户指定 5:2；横向负空间要充足，避免把 16:9 参考图直接裁成 5:2。
- 微信公众号首条使用 2.35:1。关键标题、品牌与主体必须集中在居中方形安全区附近，同时让两侧在完整横图中保持材料节奏。
- 微信公众号次条使用 1:1，只保留短标题、单一主体和少量拼图/橙色，不复制首条的全部信息密度。

## 缩略图 QA

- 在目标平台完整比例查看；
- 再按平台可能出现的居中方形裁切查看；
- 检查主标题、主体和橙色锚点是否仍成立；
- 检查文字周围是否有足够净空；
- 不以放大原图后的可读性代替真实缩略图检查。
