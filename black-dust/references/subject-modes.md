# 主体类别适配

以下规定结构保护与构图。具体笔法按 [charcoal-drawing.md](charcoal-drawing.md) 的类别表执行；这些类别不会自动开启实体碎裂或画外撒粉。

## 类别与拼图材质基线

八类主体回归和两类文字分支的默认起点如下；材质预设只控制拼图物理层，不改变各类木炭底图。静物/产品依实际明度在三个预设间选择，其余类别若偏离基线，也必须记录原因并重新检查对应明暗。

| 类别 | 拼图材质基线 | 整板识别重点 |
|---|---|---|
| 人物 | `deep-charcoal` | 脸与暗背景上的共享边仍连续可追踪 |
| 动物 | `deep-charcoal` | 毛流不能吞掉拼缝，拼缝也不能刻断毛束 |
| 静物/产品 | 暗调 `deep-charcoal`；中灰 `graphite-matte`；浅调 `ivory-board` | 玻璃、金属、布料与负空间都属于同一拼板 |
| 建筑 | `graphite-matte` | 天空、雾区、建筑面连续受同一刀模切割 |
| 风景 | `graphite-matte` | 远中近层次之上仍能读到整板而非网格滤镜 |
| 机械 | `deep-charcoal` | 深背景与高频装甲均保留低调共享边 |
| 抽象 | `ivory-board` | 留白不是未切区域，笔势与负形仍在完整拼面上 |
| 社媒封面 | `ivory-board` | 文字、留白、实物炭棒和尘区共同构成整板 |
| 中文文字 | `ivory-board` | 字形、笔画连接和留白共同受切，缺口避开关键笔画 |
| 英文文字 | `ivory-board` | 拼写、撇号、字腔、字距完整，文字区仍属于同一整板 |

## Portrait

保护五官、脸型、眼睛、发际、皮肤明暗和身份特征。拼图线可以经过脸部，但不能扭曲五官；保护区拼缝只弱化到同一材质常规强度约 75–90%，不能擦掉到脸重新像贴在拼板上的平面肖像。缺块优先背景、头发外缘或肩部之外。需要从脸部取块时必须使用 exact_composite。

先确认是保留内容参考的身份，还是只借用风格生成新人物。不要把皮肤变成均匀龟裂陶土；眼口处拼缝按保护比例降低，但共享边仍须可追踪。首轮三组缺块，缩略图仍应先看到脸。

## Animal

保护眼睛、鼻口、耳形、轮廓、毛发方向和物种特征。木炭笔触顺应毛流，拼缝不能制造错误表情。缺块优先背景或蓬松毛发外围。

按毛流组织明暗而非锐化每根毛；胸毛用连续长短笔触收束，不做粉尘围脖。检查物种耳形和眼睛间距，不把参考狼的结构照搬到其他动物。

## Still Life / Object / Product

保护比例、轮廓、接口、品牌标识、关键零件和物体之间的接触关系。玻璃、金属、布料、木材必须靠高光和笔触区分。绘画默认物体完整；明确尘化任务才从指定断裂端点产生粉尘，不能抹掉产品识别。主体高频细节不能成为隐藏拼缝的理由：物体、布面与背景均须读成同一整板，拼缝之外保持原有材质像素。

不能只按低细节选洞而让三个洞在顶部排队。先保护完整产品与玻璃外轮廓，再检查缺口位置的行列重复。通用虚构相机的测试不证明特定商业产品结构/Logo 保真。

## Architecture

保护透视、垂直线、结构连接、建筑轮廓和地平线。拼图线不能替代或扭曲建筑几何；缺块优先天空、雾区、外墙次要平面和边缘负空间。

自然雾景通过轻擦灰面和留白表现；建筑的炭笔侧锋、墙面灰阶、结构重线本身就是风格，不要求前景另加实体崩解。不改动建筑和引导水道。缺块应取自带有可辨认但次要的云层、墙面或岸线过渡，避免纯黑/纯白块造成“看不出来自哪里”；必须同时查看 assembled proof，确认塔身、屋檐、岸线与水道拼回后连续。

## Landscape

保护地形层次、山体轮廓、河流/道路引导线和空间深度。可以使用较密拼图面，但缺块不得切断主要引导线或让远近层次塌陷。

不要让黑色散落块集中悬在最亮天空成为第一焦点。近岩笔触随岩层方向，远山减少笔触频率；默认不添加角落炭粉或颗粒云。

## Mechanical / Character Armor

保护面甲、眼部、关节、对称结构和金属反光。用石墨高光维持硬表面层次，避免在关键机械接合处挖块。

保护框应覆盖肩甲外轮廓，不能只框头胸；否则散落块会盖住仍未受保护的肩部。无可读负空间时先调整底图的深灰层次，不能用亮描边伪造可读性。禁止全身碎石片纹理冒充金属。

## Abstract / Art

先区分抽象炭笔绘画与实体炭雕。绘画以笔势、灰面叠压和擦除负形构成；炭雕任务才允许实体崩解与颗粒尺度变化。仍必须保留主要视觉重心；一一匹配、无镜像不因抽象化而放宽。

抽象必须有清晰结构锚点，例如宽炭笔弧线与擦白缺段，而不是任意烟团。明确要求实物断裂时，才检查实体段、断面、粗块与细粉的尺度差。

## Social Cover

先确定平台画布和文字安全区，再安排主体、尘化和缺块。主标题、`SKILL`、副标题和主体辨识度高于洞口与散件的戏剧性，但文字与安全留白仍属于完整拼板，不能做成悬浮在未切底纸上的排版层。使用 [social-cover-system.md](social-cover-system.md) 的三阶段流程。模型文字实验稿即使单张校对正确，也不能当作稳定排字能力或精确品牌色证明。

## Chinese / English Typography

先在无拼缝连续底图中完成确定性排版与逐字校对，再依 [typography-system.md](typography-system.md) 建保护框和切块。中文保护关键笔画连接、字腔与标点；英文保护拼写、撇号、字腔、基线和字距。拼缝可以低调穿过字面，缺口默认避开识别核心；若明确从文字中取块，必须交付 exact composite 与 assembled proof。

## 多类别

当一幅图同时包含多个类别，采用更严格的保护集合。例如“人物手持产品”同时保护脸、手、产品轮廓和品牌；“建筑风景”同时保护建筑透视与地形引导线。
