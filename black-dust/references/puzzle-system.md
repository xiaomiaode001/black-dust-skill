# Puzzle System

## 两种执行等级

### exact_composite（默认推荐）

先完成连续底图，再用同一块几何 mask 同时制造缺口和取出块。块面像素从缺口原位置裁取，因此形状、内容、颜色和光线可以验证。

### prompt_only

让生成模型直接绘制拼图。只适合草图、视觉方向或不需要精确回拼的任务。输出必须说明：形状和内容匹配尚未通过确定性验证。

## 完整表面

- 把整张画布视为一张连续印刷、再压切开的实体拼面，而不是一幅平面画与几个外加道具。原画的留白、炭笔边缘、主体乃至实物炭棒图像都属于这张拼面。
- 验收顺序是 **board first, pairs second**：全图适配屏幕时，先确认即使遮住洞口和散件，整幅仍一眼读成由标准拼块组成的完整板；再评价缺块与散件的对应关系和构图节奏。缺口很显眼但其余画面像连续平面，不通过。
- full-frame jigsaw construction；
- seams cover the image edge-to-edge；
- no decorative frame / no outer border；
- premium matte paperboard、fine paper grain、narrow pressed seam、soft contact shadow；
- 避免儿童彩色拼图、塑料玩具、过厚纸板或夸张立体块。

### `standard-v5` 标准刀模与压切层

- 默认 `standard` 必须记录为 `standard-v5`：成熟商品拼图的清楚圆旋钮、宽颈和圆滑凹槽，相邻两块从同一条边界生成，凸/凹只是共享边的两种极性，不能靠两条独立轮廓碰巧贴合。v5 保持圆头半径可读，把颈部半宽扩大为圆头半径约 50–58%，并用连续切线接回平直刀线；不得出现细小夹口、内卷尖钩或突然折向。轻微变化只允许发生在旋钮中心偏移和正负边组合，不能把标准轮廓扭成任意波浪。v4 只用于旧 manifest 回放审计，不再作为新输出默认。
- 每条可见拼缝只占窄切割带。生产基线沿共享边的一侧建立约 2px 压切暗槽，再在同一左上光源下建立两侧方向性肩部：受光肩轻抬、背光肩轻压，并用较宽的近、中、远三段低强度衰减保持适屏可读性。亮度必须相对该像素附近的原画明度增减；固定灰线、固定白线、固定黑线或整幅统一色值均不通过。
- 深木炭底上的线、排线、擦揉和纸齿必须在拼块顶面连续保留。暗槽和双肩不能铺满块面，也不能以提亮整块来换取可见性。
- 保护区不是“无拼缝区”。眼睛、五官、产品核心结构、建筑轮廓和标题上的缝可将窄带物理层的 alpha/对比系数减弱至该材质常规强度约 75–90%，但必须仍能追踪共享边界；若弱到主体区域重新像一张平面画，整板识别失败。
- 物理处理只能落在拼缝窄带、洞口和散件占用范围。画面其余像素保持连续底图，不添加全图 emboss/normal-map、棋盘式块间明暗、白色轮廓、统一龟裂纹或随机墨点。

## 材质预设

每次合成必须显式记录一个预设。预设控制接缝、切壁和影子的相对强度，不重绘底图，也不改变散件顶面。

| 预设 | 基线类别 | 视觉目标 |
|---|---|---|
| `deep-charcoal` | 人物、动物、机械；暗调静物/产品 | 深炭面上拼缝仍可读，肩光克制，避免白描边与死黑散件 |
| `graphite-matte` | 建筑、风景；中灰物体 | 石墨哑光、清楚但不抢结构的中等对比压切 |
| `ivory-board` | 抽象、社媒封面；浅调产品 | 象牙纸上的细暗槽与轻壁影，避免黑线网格和塑料高光 |

类别是起点，不覆盖实际底图明度：静物/产品可在 `deep-charcoal`、`graphite-matte`、`ivory-board` 间切换，但必须说明原因并对对应明度回测。预设不允许靠改变原画曝光来获得拼缝可读性。

## 缺块规划

一般主体与社媒封面首轮使用 3 组，即 3 个洞口与 3 个同源散件。若负空间紧张，先调整网格、排版留白或三组位置；不能擅自减数，也不能把洞口或散件移到主体上。确认层级后，一般主体可按用户要求增至 4–6 组。位置非对称，优先级如下：

1. 负空间；
2. 绘画笔触的虚实/灰阶过渡带（实物尘化任务才使用颗粒过渡带）；
3. 画面边缘附近；
4. 不破坏主要引导线的节奏节点。

默认保护的不是“主体中心点”，而是完整语义主体占用：人物头肩与手势、动物全头与胸颈、产品/炭棒的完整外轮廓和断口、粉尘与碎屑运动路径、机械外甲、建筑剪影与地基、地平线交点、关键投影和主要引导线；Logo、主标题、副标题与标点另行全框保护。只有 `allow_subject_missing_piece: true` 才能从保护区域取块。

保护必须同时约束两个足迹：缺口源格的完整 mask，以及散件目标在旋转、当前材质侧壁、近影与远影扩张后的完整占用框。`ivory-board` 在 1980×792 横版按约 4px 薄切壁计算并随尺寸等比缩放，`deep-charcoal` / `graphite-matte` 通常按 5–6px；任一足迹与完整主体相交都不通过。不能以“只压到粉尘”“没有挡住产品中心”或“影子很淡”为理由放行。

散落块必须仍在画面表面，尺寸等于原网格，允许小角度旋转；不能镜像或漂浮。其顶面是缺口原位置未经调色、锐化、纹理化的裁片，只有极窄面缘可以加入基于源明度的压切斜面，中央图案保持原像素；下方只加入材质对应的分层纸板侧壁、近距离接触影与更软的远距离落影，并与拼面使用同一左上光源。浅色 `ivory-board` 禁止固定深色外沿和整圈白边；只有一层平移阴影的贴纸感不通过。

设计感不等于平均分散：洞口负责留白中的“停顿”，散件负责视线的“回应”，可以是一小簇加一处远端反拍，也可以是一条斜向节奏；避免洞和块都沿相同边距排队、在单一象限堆成装饰，或左右均衡复制。先分别规划「取走哪里」和「放到哪里」，再观察二者与标题、主体和平台裁切共同形成的重心。深色块优先从有真实灰阶变化的区域取出；其图案在目标背景上仍要可读。主体安全高于内容可识别：若负空间只有浅纸纹，先减少配对数；确需从该处取块时才把 `piece_content_policy` 切为 `any`，并以同源哈希和拼回复核证明。此处的“不规则”指构图节奏，不是把每块裁成陌生的自由形。

`standard` 是默认视觉：标准圆头、宽而清楚的颈部和凹槽，凸头位置只在边中部轻微偏移，圆弧以连续切线自然回到基线，单块一眼可识别为成熟拼图产品。`organic` 仅在用户明确要求自由手工刀模时使用；它仍须共用相邻边界，但不适合本项目当前的标准拼图参考。`classic` 只保留旧规则网格供回归对照。刀模几何的规律性与缺块/散落构图的不对称可以同时存在；几何校验通过也不等于纸板立体感、设计美感已经通过。

挑选散落块时默认使用 `piece_shape_policy: mixed`：每个取出块至少同时包含凸头与凹槽，一眼可识别为标准拼图块。四边全凸或四边全凹在数学上可以拼接，但容易像程序刻意制造的图标；只有用户明确要求自然随机分布并切换为 `any` 时才保留，不能在一组中重复出现。

同时默认使用 `piece_content_policy: recognizable`：裁片须包含足够的局部灰阶变化，让观看者能从木炭纹理、雾线、岸线或局部图案判断其来源。可识别不等于追求最高反差；在浅纸封面中，一组散件优先混合中等炭痕过渡与细纸齿/轻炭痕，避免每块都截取黑白最剧烈的粉尘区。数学上完全匹配的纯黑、纯白和近乎无纹理裁片仍会造成“散件颜色与缺口对不上”的视觉误判，因此自动选择不再优先低方差区域，手动选择也会在默认模式下拒绝这类格。若只有高反差候选，先减少缺块数或更换格位；用户明确要求在纯留白/负空间取块时才切换为 `any`，并依赖 exact-pair 与 assembled proof 证明结构对应。

## 配对数据

每组缺口与块共享唯一 `pair_id`，至少记录：

```yaml
pair_id: p-01
cell: [row, column]
source_bbox: [x0, y0, x1, y1]
edges: {north: socket, east: tab, south: tab, west: socket}
rotation_degrees: -7
mirrored: false
destination_center: [x, y]
mask_sha256: "..."
content_sha256: "..."
```

### 五项硬校验

1. **Shape match**：洞和块使用同一 mask；四边 tab/socket/flat 完全对应。
2. **Orientation match**：展示时只能旋转；记录完整角度；禁止镜像。双三次旋转会重采样边缘，反向旋转展示图不能无损恢复；像素级复位使用保存的未旋转原始块。
3. **Image content match**：块面来自 `source_bbox` 的实际底图像素，复位后图像连续。
4. **Color and light match**：继承原曝光、色彩、纹理和颗粒；只允许位移造成的新阴影。
5. **One-to-one match**：`pair_id`、洞和块数量一致且唯一；无随机洞、孤立块或重复源区域。

`mask_sha256` 必须证明洞与块共用同一几何 mask；`content_sha256` 必须对应保存的未旋转原始顶面。展示旋转、切壁和阴影不参与顶面内容哈希，不能用视觉相似代替哈希一致。

同时保存 `assembled_output` 与 `assembled_sha256`。该图是同一底图、同一刀模、同一拼缝参数下无缺口的完整拼板，用于直接查看每个裁片复位后的建筑线条、产品结构、明暗和纸面图案是否连续。它是视觉证据，也是审计资产，不能用原始无拼缝底图替代。

## 洞口物理层

洞口不是单色灰块，也不是发光描边。由底向上建立三层：

1. **paperboard substrate**：安静、与当前材质相容的纸板底；使用连续的粗尺度纤维走向和细尺度纸齿，两个尺度都应形成纤维关系而非逐像素盐胡椒噪点。不能有源图内容、棋盘纹、墨点或随机喷点。
2. **cut wall**：沿共享 mask 内缘露出分层纸板侧壁；`ivory-board` 在 1980×792 以约 4px 为基线并随尺寸等比缩放，浅纸芯保持暖色，`deep-charcoal` / `graphite-matte` 通常为 5–6px。拼缝肩部从近、中、远三段衰减，层次连续、厚度稳定，不能形成整圈同强度黑边或白边。
3. **recessed cavity polarity**：洞口必须先读成凹陷。左上入光时，底板相对洞形向右下轻微退进，上/左露出完整截面与接触暗部，下/右收成窄反光唇；两者都随底材明度变化，不能像平面投影、凸起按钮或洞内发光。

洞口、原块 mask 和散件顶面使用同一几何来源。物理层可以增加深度，但不得改变配对轮廓。

## 确定性脚本

本地有输入图且需要严格匹配时使用：

```powershell
python scripts/puzzle_compositor.py input.png output.png `
  --rows 9 --cols 16 --cut-style standard --missing-count 3 --seed 42 `
  --piece-shape-policy mixed --piece-content-policy recognizable `
  --min-piece-detail 10 --assembled-output output.assembled.png `
  --material-preset deep-charcoal `
  --protected-box 0.30,0.12,0.70,0.72 `
  --hole-color 64615B --pieces-dir output-pieces `
  --manifest output.puzzle.json
python scripts/audit_pairs.py output.puzzle.json
```

`--protected-box` 使用归一化坐标 `x0,y0,x1,y1`，可重复提供。脚本选择低细节、偏外围的非保护格，使用同一 mask 裁块和挖洞，并输出配对 manifest。

生产实现对每个稀疏洞口先取 mask 外接框并增加足以容纳切壁、反光唇和双尺度阴影的安全边距，只在该局部 patch 内生成纸纤维与形态学层，再合回已有画布。不得为少量洞口反复创建全画布纹理场；该优化只减少中间计算范围，不改变 mask、顶面像素、assembled proof 或独立配对审计。

需要设计摆位时，在同一命令中增加成组参数（坐标须按实际图像调整）：

```text
--missing-cell 1,1 --piece-placement 0.16,0.38,11
--missing-cell 3,13 --piece-placement 0.86,0.67,-15
--missing-cell 7,2 --piece-placement 0.21,0.64,7
--max-rotation 18
```

缺块格从 0 开始；`--piece-placement x,y,angle` 是归一化目标中心与旋转角，按缺块参数出现顺序一一配对。不支持缩放或镜像。目标连阴影留边一起检查，越界、撞洞、撞保护区或撞另一块时拒绝写出；重新选择位置，不靠缩块绕过。manifest 保存 `placement_mode`、`grid.cut_style` 和 `grid.geometry_version`，旧无版本记录按旧几何复核。

脚本只负责确定性拼图结构，不替代底图风格化、主体语义判断或最终文字排版。运行后仍需视觉检查：拼缝是否自然、块是否遮挡主体、构图是否平衡、接触阴影是否可信。

## 试验参数与执行边界

- 网格尽量接近正方形单元：约 16:9 横图可从 16 列 × 9 行开始；3:4 图可从 10 列 × 14 行开始。不是所有画布固定 10×16。
- 孔洞的底材色是整块纸板下方的基底，而不是把源图漂白。暗调可试 `64615B`，象牙纸可试 `B9B1A3`。这是初始值，不是通用审美保证；必须看具体画面。
- 拼缝满版但只在窄带建立 `standard-v5` 的约 2px 单侧暗槽、方向性双肩和三段低强度衰减；明暗相对局部原画计算。重要区域保留该预设约 75–90% 强度，边缘拼缝延伸至画布，不能为了去外框或保护主体把整段清空。
- 默认块形必须保持标准拼图的圆头、宽而清楚的颈部和凹槽；不规则感优先由洞与散落块的非对称编排产生，而不是扭曲刀模。
- 连续双尺度纸纤维、上/左接触暗部、下/右内壁反光、材质对应的分层侧壁与近/远两级柔接触阴影共同表达厚度。`ivory-board` 在 1980×792 用约 4px 暖色薄切壁，其他预设通常为 5–6px；禁止盐胡椒噪点、整圈亮白描边、固定深色外沿、没有方向的发光洞边、单层贴纸阴影或明显漂浮。
- 散落块需要适度而非最大背景对比；不能修改块面的亮度或纹理。浅纸封面若出现多块强黑白裁片，应先删减为 2 块或换取样格，不能靠漂白、描边或加重阴影统一它们。纯黑底造成块面不可读时，应退回底图/取块规划。
- 自动保护和摆位都是几何启发式，不识别人脸、产品或标题。人工看图设置多个保护框，必须覆盖完整主体语义足迹，洞口与散件连同旋转、侧壁和阴影都要留出空间。
- 脚本只输出无损 PNG；拒绝覆盖已有输出，重试用新版本目录。禁止输入、输出、manifest、块素材路径重合。
- 输入先按 EXIF 转正；透明图须先合成到目标纸底。单格最小 24px；完整 mask 总像素预算为 3 亿，超限须降低分辨率/密度。当前实现不是 4K 高密度无限扩展引擎。
- 手动 `--missing-cell row,col` 从 0 开始，必须唯一、数量等于 `--missing-count`，不能撞保护框。旋转限值可为 0，真实值保存在 manifest。
- 当前脚本版本的 `--knob-ratio` 允许 0.08–0.22；八类主体和两类文字按上表起步。不能只靠四边签名互补推断没有像素重叠；对 `standard-v5` 同时测试宽颈自然度、满画布唯一归属、共享边互补、块的连通性、随机种子复现、实际源图回接与 assembled proof。
- `--min-piece-detail` 是裁片 mask 内灰阶标准差阈值，默认 10；它判断的是可识别性而不是“越复杂越好”。选块目标是适度纹理和明暗过渡，不能为了追求高对比破坏主体或引导线。
- `audit_pairs.py` 读取保存的源图、输出图、原块，复查真实像素、alpha、格子对应、范围、保护区与显示块的不透明内部；不采信 manifest 内自报的 `checks`。
- 没有 `--pieces-dir` 就不能进行完整资产复核。未验证的抗锯齿边缘、纸板美感和语义完整性必须做视觉复核。

## QA

- 遮住洞口与散件后，整幅仍先读成成熟 `standard-v5` 标准拼板，而不是平面画；
- 拼图线满版且连续，无外框；
- 拼缝为约 2px 单侧暗槽、左上光源下的方向性双肩与三段低强度衰减；适屏视图先读成完整拼板，明暗相对局部原画，保护区仍保留约 75–90% 可读强度；
