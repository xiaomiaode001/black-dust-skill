# Black Dust 视觉系统

## 核心判断

Black Dust 的识别度来自“绘制/材料—结构—编辑设计”的层级关系：

1. 绘画以木炭/石墨笔触塑造形体，实物研究才呈现炭棒与粉尘的体积；
2. 整幅图被组织为可触摸的拼图表面；
3. 构图克制，像美术馆装置、高级编辑海报或艺术书封面。

底图阶段只验绘画/材料，不以缺少拼图或颗粒判失败。最终拼图与封面再验结构和编辑设计；不为品牌一致性给每类添加相同撒粉装饰。

## 材料语法

先选分支，不能共用一段“porous / brittle / fragments / dust”模板：

- `charcoal_drawing`：默认。细节是有方向、有压力变化的线和灰面，见 [charcoal-drawing.md](charcoal-drawing.md)。主体保持完整，边缘通过失边、擦揉和拖笔退出画面；默认没有离散颗粒。
- `charcoal_object`：用户/参考展示实体炭棒、炭雕或明确断裂装置。保留完整实体、实际断面与尺度变化；只有开启 `disintegration` 才要求碎块—粗粒—细粉的渐变。其物理特征如下，不应用到皮肤、毛发或金属本身。

物理特征：

- dry、brittle、porous、powdery、rough；
- 表面大部分吸光，边缘或压实处出现有限的 graphite sheen；
- 断面不规则，颗粒有重量并受重力或表面方向影响；
- 粉尘轨迹从实体断裂处产生，不能与源物体脱节。

### 实体炭棒定稿形态

品牌材料与实物炭棒场景以用户确认的“长方压制炭条 + 单端脆裂”作为审美基准。这是形态与材质标准，不要求每次复制同一根炭棒或同一构图。

- **整体比例**：低矮、修长、横向稳定的压制炭条，截面接近长方或轻微梯形；主体保留连续的坚实体量。边棱可有轻微压制不齐和磨损，但不能扭成树枝，也不能做成圆柱铅笔、圆木、规则工业砖或粗短煤块。
- **棒身表面**：主纹理沿长轴连续，表现压实炭纤维、薄片层、少量浅纵裂与局部摩擦面。大部分为吸光炭黑，只有棱边和压实面出现窄而克制的石墨反光；禁止等距龟裂、统一鳞片、蜂窝孔洞、熔岩皮或整根高亮塑料壳。
- **断裂端**：只选一个明确端点作为破裂源。断面呈不规则斜切、撕裂状片层和纤维束，外轮廓保留数个大小不同的硬折面；不能是平整锯口、软泥撕口、花朵状爆炸或所有碎片同时悬空。
- **尺度递减**：断口仍相连的片层与大碎块最重，随后过渡到较小薄片、粗粒、细粒和落入纸齿的粉末。粒径、间距和密度都随离开断口而递减，轨迹中保留不均匀露纸；远端可以稀疏消散，但不能变成黑烟、雾尾、均匀圆点喷枪或与断口脱节的装饰飞溅。
- **接触与光线**：炭条、碎片和粉末都落在同一纸面上，具有短而低的接触影和一致的单一侧向掠光。重量来自底缘压暗、断片叠压和粉末嵌入纸齿，不靠厚重 PBR 高光、悬浮阴影或发光描边。
- **构图角色**：在品牌横版中作为下半部的横向材料主轴，完整棒身负责稳定，断口和粉尘负责向一侧延伸阅读动势。文字、拼图洞口与散件必须避开棒身、断口、碎屑路径及其关键投影。

实物分支的 Prompt 应直接描述上述形—面—断—尘—影关系，不能只写 `rough charcoal stick, more texture`。若参考炭棒已经满足该标准，优先保护形态与材料，仅修复文字、拼缝或局部构图；不要为“增强质感”重新设计成另一种物体。

禁止替代物：

- 黑烟、浓雾、云团；
- 液态墨水、水彩晕染；
- 魔法光粒、星尘、火焰、爆炸；
- 均匀 Photoshop 喷枪、廉价飞散粒子；
- 无细节的纯黑色块。

海雾与空气透视是建筑/风景的正常绘画内容，以轻擦灰面和留白表现。没有尘化要求时，不再额外补前景炭渣来“证明 Black Dust”。

## 色彩场景

### gallery_ivory

- 背景：warm ivory / cream / off-white，带细纸纹；不能是冷白数码底。
- 主体：charcoal black 与 graphite gray。
- 用途：产品、实物木炭、品牌封面、编辑设计、教程封面。

### deep_charcoal

- 背景：深炭黑或石墨灰，保留可见层次而非死黑。
- 主体：亮灰木炭、石墨高光、局部纸白。
- 用途：肖像、动物、机械、暗调艺术图。

### 强调色

`Signal Orange #FF5A1F` 只用于 `SKILL`、“拼”、一块拼图、短线、编号或微小视觉锚点。不要用作大面积背景或覆盖木炭主体。`monochrome` 模式完全不使用橙色。

## 构图

- 优先保留原图主体身份、比例、姿态、光线方向、透视和视觉重心。
- 采用单一明确主体、清晰明暗组织、充足负空间和低色彩噪声。
- 显式崩解的作品才要求起点、方向和密度梯度。
- 拼图块保持标准可识别的几何语言；缺块与散落块形成非对称疏密节奏。仅当颗粒存在时纳入布局，不能为了构图先添加颗粒。
- 允许内容类别决定明暗场景，不要把所有图片强制变成象牙白封面或深黑肖像。

## 输出测试反馈形成的规则

- 绘画底图优先连续笔触，不设默认崩解起点；实物崩解才需要规划主起点，避免等量粉尘花边。
- 机械的金属不是木炭石雕：平面内部完整、边缘选择性石墨高光，裂解限于指定非关键部位，不能所有面板都碎成页岩。
- 深色背景保留局部暗灰变化；连续死黑会使真实裁出的散落块没有内容可读。
- 不用背景纹理密度掩盖结构错误。前景、中景、远景的笔触密度应有差异。
- 木炭颗粒嵌在纸齿中的细微断续，不等于画外散落墨点。少掉所有墨点以后，主体本身仍应明确像炭笔画。

## Prompt 语言顺序

按以下顺序组织核心 Prompt，减少模型误读：

1. 内容与构图；
2. 必须保护的身份/结构；
3. 媒介分支与类别画法（形—调—笔—纸；实物分支单独描述断面）；
4. 拼图表面；
5. 缺块位置与数量；
6. 色彩与光线；
7. 负面约束；
8. 平台比例或模型专属参数。
